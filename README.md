Description:
Emerald City Nursery is a C# console application that allows users to browse a selection of plants, add items to a shopping cart, and generate a final receipt showing purchased items and the total cost. This project was developed as part of a programming course to practice object-oriented programming concepts and user interaction.
Features:
Browse six different plant selections
View the product prices
Add plants to the shopping cart
Generate an itemized purchase receipt
Calculates the total order cost
What I Learned:
This project helped me practice classes, methods, user input, program flow, and cost calculations while creating an interactive console application.
